# Advent of Code

Solutions to [Advent of Code](https://adventofcode.com/) puzzles.

## Note Regarding Data Files

I have made this repository ignore data files.

For each puzzle I simply create a file called `data` in the directory of the solution code.

For Event 2015 Day 01, that path would look like this: `/events/2015/day01/data`.

This is just in case anyone else who happens upon this may input their own data in to compare solutions and get a result that is relative to them.

## Running Solutions

Solutions are designed to be ran from the parent directory.

For Event 2015 Day 01 (Python Solution), the execution sequence would look like this: `python events/2015/day01/main.py`.
